# v1.0 Acceptance Checklist

## v1.0 freeze status

Local visual agent release prep is frozen for the current stdlib Workbench.
The release path is local-first: start with `agent start`, inspect settings in
the Workbench, verify with `agent release doctor`, and keep packaging deferred.
