# v1.0 Packaging Decision

Decision: defer binary packaging for v1.0.

`agent start` and `python -m agent.cli start --cwd F:\agent` are enough for the
current local Workbench release prep. PyInstaller or Nuitka would add build
scripts, platform-specific troubleshooting, and artifact verification before
there is a clear distribution need.

Keep v1.0 focused on a stable local workflow:

- start the Workbench with `agent start`
- verify with `agent release doctor`
- keep config edits explicit and file-backed

Future trigger: add PyInstaller or Nuitka packaging when the project needs a
shareable executable for a non-developer user, and include a smoke test that
starts the packaged Workbench and reads `/api/health`.
