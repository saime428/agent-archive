# v0.6 Acceptance Checklist

v0.6 starts the Visual Workbench track. The current slice adds a local web UI
shell and a basic browser chat turn over the existing agent core and durable
run logs.

## v0.6 current status

Visual Workbench MVP shell is in progress. The browser surface can inspect
config, tools, runs, summaries, submit one synchronous chat turn at a time, and
confirm one required action with native browser confirmation. The Files panel
and Snapshots panel are read-only and do not change tool execution semantics.

## Acceptance Items

| Item | Status | Evidence |
| --- | --- | --- |
| `agent ui` starts a local workbench server | Implemented / Tested | CLI tests |
| workbench binds to localhost by default | Implemented / Tested | CLI and server tests |
| API exposes health/config/tools/runs read-only data | Implemented / Tested | UI tests |
| tools endpoint reuses the same policy categories as `agent tools list` | Implemented / Tested | UI and CLI tests |
| runs endpoint reads redacted durable run summaries and tool calls | Implemented / Tested | UI tests |
| static UI shows an Apix-style rail, run list, summary pane, and details pane | Implemented / Tested | UI asset tests |
| browser chat turn creates durable run and chat records | Implemented / Tested | UI tests |
| browser chat can resume the same session across turns | Implemented / Tested | UI tests |
| native browser confirmation can approve one required action retry | Implemented / Tested | UI tests |
| Files panel lists workspace directories and previews text files | Implemented / Tested | UI tests |
| Snapshots panel shows snapshot paths and restore hints | Implemented / Tested | UI tests |
| existing `agent run` and `agent chat` behavior remains unchanged | Implemented / Tested | CLI and regression tests |
