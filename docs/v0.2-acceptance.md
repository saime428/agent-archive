# v0.2 Acceptance Checklist

v0.2 extends the frozen v0.1 core with provider selection, skills, memory, and
disabled-by-default hooks. It does not implement v0.3 document tooling.

Summary Areas: DeepSeek, Skills, Memory, Hooks.

## Implemented and Tested

| Area | Status | Evidence |
| --- | --- | --- |
| DeepSeek config fields: `provider`, `model`, `deepseek_api_key_env` | Implemented / Tested | config and CLI tests |
| DeepSeek doctor diagnosis checks API key presence without networking | Implemented / Tested | CLI tests |
| DeepSeek OpenAI-compatible non-streaming client | Implemented / Tested | mocked client tests |
| `agent run --provider fake|deepseek --model <model>` selection | Implemented / Tested | CLI tests |
| Provider/model details are written to run summary and trace config | Implemented / Tested | loop and CLI tests |
| `agent skills list` and `agent skills show <name>` | Implemented / Tested | skills and CLI tests |
| Built-in and project skill discovery with progressive disclosure | Implemented / Tested | skills tests |
| Selected skill context is loaded under budget and marked untrusted | Implemented / Tested | loop tests |
| Skill tool hints cannot bypass policy or approval | Implemented / Tested | loop tests |
| Memory candidates are generated but not auto-accepted | Implemented / Tested | memory and loop tests |
| `agent memory review/list/accept/undo` | Implemented / Tested | memory and CLI tests |
| Memory entries include source, timestamp, status, and tombstone undo | Implemented / Tested | memory tests |
| Deterministic memory retrieval is budgeted | Implemented / Tested | memory and loop tests |
| Hooks are disabled by default | Implemented / Tested | hooks tests |
| Explicit in-process hooks write lifecycle audit logs | Implemented / Tested | hooks tests |
| Nonblocking hook failures are logged without stopping the run | Implemented / Tested | hooks tests |
| Blocking hook failures return standard error observations | Implemented / Tested | hooks tests |

## Deferred

| Item | Status | Notes |
| --- | --- | --- |
| PDF, Word, Excel, and PowerPoint tools | Deferred to v0.3 | Documents remain untrusted source material |
| Markdown and Word report generation | Deferred to v0.3 | Not part of provider/skills/memory/hooks |
| Shell-command hooks | Deferred | Needs a dedicated hook sandbox and approval policy |
| Embedding-backed memory retrieval | Deferred | v0.2 uses deterministic matching only |
| Live DeepSeek automated tests | Deferred | Default pytest must not require network or API keys |
