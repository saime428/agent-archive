# v0.4 Acceptance Checklist

v0.4 starts by making real provider connectivity explicit and diagnosable while
keeping offline development and tests stable.

Summary Areas: DeepSeek provider smoke, provider diagnostics, observation
feedback, live run visibility, offline tests.

## Implemented and Tested

| Area | Status | Evidence |
| --- | --- | --- |
| `agent provider smoke deepseek --model <model>` command | Implemented / Tested | CLI tests |
| DeepSeek provider smoke uses the configured API key env and model | Implemented / Tested | DeepSeek and CLI tests |
| provider smoke validates model output through the existing action parser | Implemented / Tested | DeepSeek tests |
| provider smoke requires a `done` action and executes no tools | Implemented / Tested | DeepSeek tests |
| missing DeepSeek API key fails fast before network access | Implemented / Tested | CLI and DeepSeek tests |
| default provider remains `fake` | Implemented / Tested | existing CLI and config tests |
| automated tests do not require a real API key or network access | Implemented / Tested | mocked transport tests |
| real provider runs receive internal action protocol guidance | Implemented / Tested | run-loop and DeepSeek tests |
| successful low-risk tool results are returned as observation feedback | Implemented / Tested | run-loop tests |
| observation feedback is marked as untrusted runtime data | Implemented / Tested | run-loop tests |
| run summaries expose `completed` and `terminal_reason` | Implemented / Tested | run-loop and CLI tests |
| CLI failure summary prints status, terminal reason, and inspect hint | Implemented / Tested | CLI tests |
| iteration-limit summaries record `failure_explanation` | Implemented / Tested | run-loop tests |

## Deferred

| Item | Status | Notes |
| --- | --- | --- |
| streaming provider responses | Deferred | Non-streaming chat completions are enough for this slice |
| provider retry/backoff policy | Deferred | Errors remain explicit and diagnostic |
| native provider tool-call schemas | Deferred | Providers must adapt into the internal action protocol |

## Manual Smoke

```powershell
$env:PYTHONPATH="src"
$env:DEEPSEEK_API_KEY="..."
python -m agent.cli provider smoke deepseek --model deepseek-v4-flash
python -m agent.cli run --provider deepseek --model deepseek-v4-flash "inspect project"
python -m agent.cli runs show <run-id>
python -m pytest tests/test_deepseek.py tests/test_cli.py tests/test_docs.py tests/test_loop.py -q
python -m pytest -q
git diff --check
```

Live run success criteria:

- `completed: true`
- `terminal_reason: done`
- `final` contains a natural language answer

Live run failure criteria:

- `completed: false`
- `terminal_reason` explains the stop reason
- `failure_explanation` in `summary.md` gives the operator-readable cause
