# v0.7 Acceptance Checklist

v0.7 closes the current Visual Workbench product shell without changing the
core action protocol or adding a frontend framework.

## v0.7 freeze status

Visual Workbench product shell is frozen for v0.7. The static Workbench shell
can show runs, trace, files, snapshots, diffs, restore controls, status, safe
refresh, activity, and the Task Review panel. The shell remains plain
HTML/CSS/JS over the stdlib HTTP server until documented migration triggers
actually appear.

## Success Criteria

- Workbench opens and keeps the static shell.
- Selecting a run shows summary, trace, snapshots, and Task Review panel.
- Refresh does not overwrite an open editor or pending approval.
- No Vue/Vite, Electron/Tauri, or new frontend dependency is required for v0.7.
