# v0.6 Acceptance Checklist

v0.6 starts the Visual Workbench track. The current slice adds a local web UI
shell and a basic browser chat turn over the existing agent core and durable
run logs.

## v0.6 current status

Visual Workbench MVP shell is in progress. The browser surface can inspect
config, tools, runs, summaries, submit one synchronous chat turn at a time, and
confirm one required action with a custom approval panel. The Files panel can
list workspace files and open text files in a minimal file editor. The Save
button calls `/api/file/save` after custom-panel approval and records a run
snapshot before writing. The Snapshots panel and Diff Viewer remain focused on
inspection and recovery. The Restore button is an explicit custom-panel recovery
action and does not change agent tool execution semantics. The Activity panel
provides status-level live feedback without changing the underlying synchronous
browser chat request.
