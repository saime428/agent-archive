# v0.5 Acceptance Checklist

v0.5 turns the single-run CLI into a minimal interactive terminal agent while
preserving the structured action protocol and the existing safety model.

Summary Areas: `agent chat`, ConversationState, interactive approval, session
persistence, explicit context references, status-level live output.

## v0.5 freeze status

Interactive Terminal Agent MVP is frozen. The current v0.5 scope covers the
terminal chat loop, session persistence and resume, bounded history context,
interactive approval, explicit file/directory references, DeepSeek streaming
preview, local slash commands, and operator-readable status/transcript output.

## manual smoke

```powershell
$env:PYTHONPATH="src"
python -m agent.cli chat --cwd F:\agent
python -m agent.cli chat --cwd F:\agent --provider deepseek --model deepseek-v4-flash
python -m agent.cli chat --cwd F:\agent --resume <chat-id>
python -m agent.cli runs show <run-id>
python -m agent.cli run --cwd F:\agent "inspect project"
python -m pytest tests/test_chat.py tests/test_cli.py tests/test_deepseek.py tests/test_docs.py -q
python -m pytest -q
git diff --check
```

live chat success criteria:

- Chat prints `chat_id`, per-turn `status`, `completed`, `terminal_reason`, and `final`.
- DeepSeek chat prints `raw model response preview` before the parsed action result.
- A second turn receives bounded `UNTRUSTED CONVERSATION CONTEXT`.
- Confirmation-required actions in chat ask for approval before execution.
- Denying approval returns `APPROVAL_DENIED` without applying the action.
- `/status` reports current session state and `/transcript` reports recent turns.
- Non-chat runs still fail fast when approval is required.
