# v0.9 Acceptance Checklist

v0.9 starts the audit and resilience track. The first slices make existing
runs, workspace state, and memory state easier to scan, replay, and filter in
the Workbench without executing tests, rerunning tools, or mutating workspace
files.

## Current Slice

Run Risk Filter and Run Replay are implemented in the static Workbench.
`/api/runs` exposes each run's `status` and `risk_level`, and the sidebar can
filter runs by risk. Run detail now exposes a read-only `replay` built from
stored tool calls. Log Filters narrow Trace and Run Replay locally by action,
status, summary text, and terminal state. Workspace Risk exposes read-only
`workspace_risk` hints from `/api/health`. Memory Review exposes read-only
`memory_review` candidates and active entries. This remains read-only.
