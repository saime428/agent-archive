# v0.3 Acceptance Checklist

v0.3 adds local document research and report-generation capabilities while
keeping document contents isolated as untrusted source material.

Summary Areas: PDF, Office, Reports, prompt-injection isolation.

## v0.3 freeze status

Core Document MVP is frozen for v0.3. The current release includes low-risk
document readers, source-grounded Markdown report writing, dependency
diagnostics, sandboxing, budget limits, approval fail-fast, dry-run behavior,
snapshots, durable logs, and redaction coverage inherited from the core loop.
