# v0.6 Acceptance Checklist

v0.6 completes the first Visual Workbench MVP over the existing agent core and
durable run logs.

## v0.6 freeze status

Visual Workbench MVP is frozen for v0.6. The browser surface can inspect config,
tools, runs, summaries, traces, snapshots, and diffs; submit one synchronous
chat turn at a time; confirm one required action with a custom approval panel;
edit text files with snapshot protection; restore snapshots; and keep provider,
model, session, DeepSeek key presence, and refresh state visible. Deferred work
stays limited to richer frontend architecture, browser token streaming, larger
approval queues, and packaged desktop shells.

## workbench success criteria

- Runs Dashboard loads recent runs and selecting a run shows summary, trace, and snapshots.
- Status Bar shows workspace, provider, model, session, DeepSeek key presence, and last refresh.
- Browser chat turn creates a durable run and shows status/final output.
- Approval panel handles confirmation-required chat retries, file saves, and snapshot restores.
- Files panel opens text files in the file editor; Save button writes through `/api/file/save` with a snapshot.
- Diff Viewer shows `/api/diff` output and Snapshots panel shows restore hints.
- Refresh does not overwrite open editors or approvals.
